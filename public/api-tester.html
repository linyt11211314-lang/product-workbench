? 说明

· 该接口只接受 POST 请求（浏览器地址栏打开是 GET，会返回提示）
· 接口从环境变量 DEEPSEEK_API_KEY 读取 Key，未配置时会返回对应提示

· 等价 cURL： curl -X POST https:///api/listing/generate -H "Content-Type: application/json" -d '{"product_name":"...","material":"...","key_points":"..."}'
